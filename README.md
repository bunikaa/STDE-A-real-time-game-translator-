# stde — перекладач тексту з ігор

Оверлей-перекладач: захоплює текст з екрана гри, розпізнає його (OCR)
і показує у напівпрозорому вікні поверх гри.

Перша ціль — гра Monster Prom, англійська → українська (пізніше з можливістю
змінювати мови). Усе працює **локально**, без хмарних сервісів і без потужної
відеокарти. Проєкт водночас навчальний — вивчення Python і роботи з нейромережами.

## Файли

- `capture.py` — захоплення області екрана
- `ocr.py` — розпізнавання тексту (OCR)
- `overlay.py` — вікно поверх гри
- `translator.py` — переклад тексту (нейромережа opus-mt-en-uk)
- `main.py` — усе разом: потоки, черга, детект зміни кадру

## Документація

- `ROADMAP.md` — план проєкту за етапами

## Як запустити

```powershell
.venv\Scripts\Activate.ps1   # увімкнути віртуальне оточення
python main.py               # запустити перекладач
```
