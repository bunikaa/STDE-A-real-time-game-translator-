# stde — перекладач тексту з ігор

Оверлей-перекладач: захоплює текст з екрана гри, розпізнає його (OCR)
і показує переклад у напівпрозорому вікні поверх гри.

Перша ціль — гра Monster Prom, англійська → українська. Усе працює
**локально**, без хмарних сервісів і без потужної відеокарти. Проєкт водночас
навчальний — вивчення Python і роботи з нейромережами.

## Як це працює

Захоплення екрана → OCR (EasyOCR) → нормалізація сленгу → переклад (модель
NLLB) → напівпрозоре вікно поверх гри. Повільні кроки винесені в окремий потік,
тому вікно не зависає; кадр розпізнається лише коли зображення змінилося.

## Файли

- `capture.py` — захоплення області екрана
- `ocr.py` — розпізнавання тексту (EasyOCR)
- `glossary.py` — словник сленгу: нормалізує розмовну англійську перед перекладом
- `translator_class.py` — переклад (клас `Translator`, модель NLLB) з кешем
- `overlay.py` — вікно поверх гри
- `main.py` — усе разом: потоки, черга, детект зміни кадру

## Встановлення

Потрібен **Python 3.12** (містить `tkinter` для вікна).

```powershell
git clone https://github.com/bunikaa/stde.git
cd stde
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Під час **першого** запуску автоматично завантажаться моделі (NLLB ~2.4 ГБ
та EasyOCR ~100 МБ) — інтернет потрібен лише раз, далі програма працює офлайн.

## Як запустити

```powershell
.venv\Scripts\Activate.ps1   # увімкнути віртуальне оточення
python main.py               # запустити перекладач
```

Перед запуском відкоригуй область захоплення `REGION` у `capture.py`
під свій екран і розташування тексту в грі. Клік по вікну перекладу — закрити.
