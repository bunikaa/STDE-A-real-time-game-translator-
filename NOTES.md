## Большая картина — что мы строим

Переводчик текста из игры — это **конвейер** из четырёх шагов:

```
[Захват экрана] → [OCR: картинка→текст] → [Перевод] → [Показ в окне]
   capture.py          ocr.py              (позже)      overlay.py
```

Каждый шаг — отдельный файл, отдельная задача. Пока готовы 1, 2 и 4.
Дальше (этап 4) соединим их в одну программу.

## Файл за файлом

### capture.py — фотограф
- Снимает **прямоугольник экрана** и сохраняет в `capture.png`.
- Библиотека `mss`.
- `REGION` — это **словарь** (dict) с координатами: `left`, `top`, `width`, `height`.
- Координаты в пикселях. Точка (0,0) — левый верхний угол экрана.
- Ключевая идея: снимается **то, что сейчас на экране** в этих координатах.
  Хочешь снять игру — игра должна быть видна в этом месте.

### ocr.py — читатель
- Открывает `capture.png`, распознаёт буквы, возвращает текст.
- Это **нейросеть** (движок Windows, обёртка `winocr`) + `Pillow` для картинок.
- `recognize_text(path)` — открывает картинку, прогоняет через `preprocess`, распознаёт.
- `preprocess(image)` — подготовка картинки, чтобы OCR читал точнее:
  - увеличить (`resize`),
  - сделать чёрно-белой (`convert("L")`),
  - инвертировать цвета (`ImageOps.invert`) — светлый текст на тёмном → тёмный на светлом.
- Главный урок этапа: **измерил → изменил ОДНО → снова измерил.**
  Обрезка (убрать фон) помогла больше всего.

### overlay.py — плашка поверх игры
- Окно поверх всего, показывает текст.
- Библиотека `tkinter` (встроенная).
- Настройки окна:
  - `overrideredirect(True)` — без рамки и заголовка,
  - `attributes("-topmost", True)` — всегда сверху,
  - `attributes("-alpha", 0.85)` — полупрозрачность,
  - `geometry("ШxВ+X+Y")` — размер и позиция.
- `Label` — надпись, `pack()` — размещает её.
- `mainloop()` — цикл окна, держит его на экране.

## Навыки (не про код, но важные)

- **Терминал:** команда — это действие (печатаешь + Enter), а не файл.
- **Читать ошибки:** ищи человеческую фразу среди технического текста.
  Трассировку читай снизу вверх, смотри на стрелки `^^^`.
- **Warning ≠ Error:** warning = «выполнил, но заметь»; error = «остановился».
- **venv:** отдельная коробка с пакетами под проект. Активируется `Activate.ps1`,
  видно по `(.venv)` слева. У каждого venv свои пакеты (изоляция).
- **git:** `add` (подготовить) → `commit -m "..."` (снимок). `status` — что готово.
  `.gitignore` — что не хранить (venv, картинки, модели).
- **Редактор:** правишь → `Ctrl+S` (белая точка ● = не сохранено) → запускаешь.

## Понятия Python

- **Функция:** `def имя():` — определяет; `имя()` — вызывает. Без вызова молчит.
- **Переменная:** `x = 5` — имя для значения.
- **Словарь vs объект — как достать значение:**
  - объект: через точку — `image.size`,
  - словарь: через скобки — `result["text"]`.
- **import:** подключает код — и чужие библиотеки, и свои файлы.
- **`if __name__ == "__main__":`** — «выполни, только если файл запущен напрямую,
  а не импортирован». Защищает от автозапуска при импорте.
- **Имена сверяются буква в букву:** `mss.mss` ≠ `mss.MSS`, `overlay` ≠ `ovarlay`.
